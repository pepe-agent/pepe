# Release Notes 0.13.1

A release with one single subject: **the permission prompt now explains why it's asking again**.

---

## 🔧 Improvement

### The permission prompt now explains itself mid-task

After an agent reads something from outside the conversation (a fetched page, an MCP tool's result), the turn gets marked "untrusted," and for as long as that lasts, a "session" or "always" approval you already granted stops counting, for safety. Only "Allow for the rest of this task" keeps working during that window.

The problem was that, until now, the buttons all appeared with the same weight, with no explanation at all. Someone who clicked "session" or "always" out of habit got caught off guard: the next risky call asked for permission again, with no way to tell why. A task that should have taken 2 or 3 clicks turned into 10.

Now the prompt says, right there: *"This task read something from outside the conversation, so a 'session'/'always' approval you already granted doesn't apply here. Choose 'Allow for the rest of this task' to stop being asked again for the rest of it."*, and the right button is marked as **recommended**. In the dashboard, it also gets a visual highlight.

This applies to all three ways of talking to Pepe: Telegram, the dashboard chat, and the terminal (`pepe chat`).

📍 *Where to see it: any permission prompt that shows up after the agent reads something from outside*
