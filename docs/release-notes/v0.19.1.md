# Release Notes 0.19.1

A small follow-up release: the Windows binary is back.

---

## 🐛 Fixes

### The Windows binary works again, with Insight included

The standalone Windows download had stopped building. Two of Insight's own pieces each depend on a native component their maker only publishes for Linux and macOS, not native Windows: the neural tier (EXLA) and the gradient-boosted-trees tier (EXGBoost). Neither gap is something we can close ourselves, so this Windows build now leaves both out.

Everything else works exactly the same as on any other platform. All four kinds of question Insight answers still work on Windows: classification, regression, trend forecasting, and clustering, all fit with logistic/linear regression and k-means. What's missing is only the two larger algorithm tiers, which matter only past tens of thousands of rows of data.

If you ask for one of those tiers by name on a Windows install, you get a clear message saying it isn't available in that build, instead of a crash partway through training. Left on automatic (the default), Pepe simply steps down to the largest tier this build actually has.

📍 *Where to find it: the `curl`/installer download page, Windows build*
