# Release Notes 0.10.2

Hi! This is a small, focused release: a fix for a real bug found while using `browser` in Docker.

---

## 🐛 Fixes

### Browser now works in Docker and Linux containers

The `browser` tool shipped in the previous version had a serious problem in containerized environments (Docker, Kubernetes, and so on): it hung completely trying to start Chrome. The cause: Chrome looks for a "D-Bus session bus" that doesn't exist inside a container, it kept trying to connect, timed out, and the browser never opened.

This affected anyone running Pepe in Docker, including the official image. It now works: we handle the problem the same way headless CI does (redirect the D-Bus lookup somewhere that fails fast instead of retrying), and we widened the timeout a bit for slow startups on loaded machines.

📍 *Where to use it: automatically, if you were using Docker*

### Website: XSS security fix

The `astro` dependency was updated to fix three reflected XSS flaws in the documentation site's build tooling (two of them with a published CVE). This doesn't affect the Pepe app itself, only the tooling that builds the help pages.
