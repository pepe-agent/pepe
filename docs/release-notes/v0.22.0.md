# Release Notes 0.22.0

Test a model connection with one click, let an agent route a channel by name, fuller traces, and a round of fixes for the dashboard chat.

---

## ✨ What's new

### Test a model connection with one click

Every connection on the Models page now has a Test button. It sends one tiny message through the connection and tells you right on the card whether it works, and how long the answer took, or why it failed, in the provider's own words (for example "HTTP 401: Incorrect API key provided"). A test never counts against the connection, so a failed one does not put it on cooldown.

📍 *Where to find it: Models, the Test button on each connection*

### An agent can route a channel without knowing its key

Asking an agent to set up "this Slack channel goes to that agent" now works from any conversation. The agent can list the connections and channels that exist and where each one is routed, then bind or unbind a channel by naming the connection and the channel. Before, it had to edit the configuration by hand with the right key, and often got it wrong.

📍 *Where to find it: ask an agent that has the `manage_channel` tool*

### Traces say where a task came from

The trace of a task now shows the channel, the conversation, the person, the agent, the model and provider used, the fallbacks and how many tools the agent had.

📍 *Where to find it: Traces, then open any task*

---

## 🐛 Fixes

- **The chat sidebar no longer crashes while a task is running.** A task in progress was being listed as if it were a conversation, which broke the conversation list every few seconds and inflated the live session count on the overview. Thanks to LG (@latesh) for the fix.
- **Files the agent generates in the dashboard chat now appear right after the reply that produced them**, instead of piling up under the whole conversation. They are still there when you reopen it, they are deleted together with the conversation, and download links no longer expire after 24 hours.
- **A task no longer ends as "interrupted" when a tool's output was cut in the middle of an accented character.**
- **An agent can no longer restart Pepe from inside its own task** by calling the `pepe` binary with its full path, which used to kill the running conversation.
- **Searching past conversations reads traces in small batches** instead of loading every trace of the project at once.
