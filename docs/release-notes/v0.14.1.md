# Release Notes 0.14.1

A release with one single subject: **the Settings screen no longer squeezes the config.json editor**.

---

## 🐛 Fix

### The config.json editor now has a guaranteed minimum height

In version 0.14.0, we tried to fix the problem where the change-history list took up so much space that the `config.json` editor became tiny and nearly unusable. That fix only capped the history's size, but the editor itself still had no guaranteed minimum height, so it kept shrinking down to almost nothing whenever the page had a lot to show (history plus the Media section).

The editor now has a guaranteed minimum height, so the page scrolls down to it instead of squeezing it. If you have a lot of recent changes or a lot of media configured, the page still shows everything, just in order now, with each section in its own space.

📍 *Where to see it: Dashboard → Settings*
