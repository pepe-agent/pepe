# Release Notes 0.20.0

A new look for the dashboard, charts that show how things are going, and agents that can send you a chart.

---

## ✨ What's new

### The dashboard, redesigned

Every page now follows one pattern: darker, calmer surfaces, larger text, fields and buttons that line up, and our own confirmation dialogs instead of the browser's. The sidebar keeps its scroll position when you click an item, everything you can press shows the hand cursor, and the short help text under each field is now one plain sentence, in English, Portuguese (Brazil and Portugal) and Spanish.

The Portuguese and Spanish texts were rewritten to read as if written in that language, not translated.

📍 *Where to find it: any dashboard page*

### An overview that tells you how it's going

The overview is split into four tabs so nothing scrolls forever: Summary, Trends, How it's going, and Usage.

- **Trends** compares this week (or this month) with the same point of the previous one: spend, tokens, runs and errors, each with how much it moved.
- **How it's going** is the good news: success rate (with a 95% reference line), typical reply time, how much of the input the provider's cache served and what that saved you, the busiest hours of the day, and which channels conversations come from.

The Usage page also shows input, output and cache tokens side by side.

📍 *Where to find it: Overview, then the tabs at the top*

### Agents can send you charts

A new `chart` tool lets an agent draw a bar, line or pie chart from numbers it already has and send it as an image: an inline photo on Telegram, and right in the conversation in the dashboard. The picture is drawn by Pepe itself in the dashboard's colors; nothing leaves your machine. Turn it on for an agent like any tool.

📍 *Where to find it: Agents, Capabilities tab (or `mix pepe agent tools NAME --add chart`)*

### Edit an agent in tabs, and never lose your changes

The agent editor is split into Persona, Model, Capabilities, Access and Limits. Every change is kept as a draft as you go, and the Save button publishes it.

📍 *Where to find it: Agents, then Edit*

### Configuration, in tabs

The page formerly called "Config file" is now Configuration, with a tab each for General (language and updates), Voice, History and the raw settings file. Each section saves on its own. Privacy moved to the System group in the sidebar, next to API tokens and Configuration.

📍 *Where to find it: sidebar, System*

### More, in short

- The chat shows the same top bar as every other page, and a chat nobody has named is called "New chat" instead of a random number.
- Model connections show the price of cached input, and the monthly tokens card separates new tokens from cached ones.
- A new `-full` Docker image adds OCR, PDF and image tools, `ffmpeg`, more interpreters and the 1Password CLI.
- New Pepe logo with the name and "agent runtime" in one image, in a dark and a light version.

---

## 🐛 Fixes

- **`/goal` works again with hosted API connections and with subscription logins.** The reviewer could not be reached on either, because the output-length limit was sent in a form those providers reject. Now each provider gets the form it accepts.
- **The Docker image no longer crashes on boot** when an optional native component can't load.
- **An agent that may not manage another agent can no longer do it through a side door**, and a tool call its own route list would refuse is answered straight away instead of waiting for someone's approval.
- **`fetch_url` is safer:** it connects to the exact address it checked, closing a gap where a site could swap the address between the check and the request.
- **Secrets with no recognizable shape are now caught** when Pepe redacts text, not only the well-known formats.
- **Telegram and Slack replies and delivery** are more reliable, pictures arrive as real photos, and a bot with no agent or model configured yet says so in plain words.
- **The sidebar no longer jumps back to the top** when you click an item, and tabs no longer shift the page under you.
