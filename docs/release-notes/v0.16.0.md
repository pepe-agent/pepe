# Release Notes 0.16.0

A small release focused on **Telegram diagnostics** and **dashboard visibility**.

---

## ✨ What's New

### Diagnostic log when a button tap is denied on Telegram

Now, when someone taps a permission button (or a model-choice button) on Telegram and the action is denied, Pepe logs everything: who it was, what their user ID was, what Telegram said about their identity. Before, nothing was recorded.

This helps diagnose one specific, confusing problem: when someone can chat normally in a group, but every time they tap a permission button they get "not authorized." The usual culprit is a "send as" identity (an anonymous group admin, or a channel linked to the group) that changes the person's ID just for that one tap, with nothing actually wrong in the configuration.

📍 *Where to see it: in Pepe's logs, search for "[telegram] denied"*

### Pepe's version now shows in the dashboard

The dashboard's sidebar (where it says "Local Panel") now shows which version of Pepe is running right now. Before, the only way to check was opening a terminal and running `mix pepe version`.

📍 *Where to see it: Dashboard › bottom left corner, next to "Local Panel"*
